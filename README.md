# 📘 블루애드온 (BkueAddon)

**AbilityWar** 기반으로 제작된 커스텀 능력 애드온입니다.

다양한 신규 능력과 콘텐츠를 추가하여 AbilityWar를 더욱 재미있게 즐길 수 있도록 제작되었습니다.

# 📖 능력 및 콘텐츠

블루애드온은 다양한 개성 있는 능력과 콘텐츠를 지속적으로 추가하고 있습니다.

새로운 능력과 아이디어는 업데이트를 통해 계속 추가될 예정입니다.
