# 📘 BkueAddon

**BkueAddon**은 **AbilityWar**을 기반으로 만든 커스텀 애드온입니다.

새로운 능력과 콘텐츠를 추가해 AbilityWar를 더욱 재미있게 즐길 수 있도록 제작했습니다.

> **안내:** 개발자인 저는 학생 신분이므로 업데이트가 다소 늦어질 수 있는 점 양해부탁드립니다.

---

## ✨ 주요 내용

- 🧩 다양한 커스텀 능력
- 🎮 새로운 게임 콘텐츠
- 💡 지속적인 능력 및 콘텐츠 추가
- 🛠️ 커뮤니티 피드백 반영
